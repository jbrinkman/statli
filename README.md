# Statli

A project status tracking and weekly status report generator for team management.

## Overview

Statli is an application designed to help teams track work tasks and generate professional weekly status reports. It provides a streamlined way to manage project status information and automatically generate formatted status reports in markdown.

## Features

- **Task Management**: Define and track work tasks with key subtasks
- **Status Tracking**: Monitor task states (not started, in progress, complete, etc.)
- **Notes & Documentation**: Capture important notes about tasks and subtasks
- **Status Report Generation**: Automatically generate weekly status reports with:
  - Customizable report titles with date suffixes
  - Email recipient configuration
  - Executive summary
  - Highlights and lowlights
  - Work accomplished sections
  - Additional customizable sections
- **Markdown Export**: Generate reports in markdown format for easy sharing
